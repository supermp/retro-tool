# 复古游戏工具

一个命令行 TUI 工具，用于整理本机复古游戏目录，并把所选目录安装到目标盘符，同时生成 EmulationStation 风格的 `gamelist.xml`。

---

## 主要功能

- **安装游戏**：扫描当前目录下的游戏子目录，按需选择后复制到目标盘符，并按系统规则映射目录名（如 `GBA` → `gba`）。
- **生成 Gamelist**：扫描游戏目录并自动匹配 `boxart/` 下的封面图，生成 `gamelist.xml`。

---

## 系统要求

- Windows 10 / 11（主要支持平台）
- 可在非 Windows 平台编译，但磁盘识别功能仅为占位实现

---

## 使用

将 `retro-tool.exe` 放到要整理的游戏目录父级目录（也就是要扫描的 ROM 根目录），运行后会扫描当前目录下的所有子目录。随后按界面提示：

1. 选择要处理的游戏目录
2. 选择操作：安装游戏 / 生成 Gamelist
3. 选择系统类型
4. 选择目标盘符
5. 确认后执行

---

## 目录约定

```text
游戏根目录/
├── GBA/
│   ├── Pokemon.gba
│   └── boxart/
│       └── Pokemon.png
├── PS/
│   └── ...
```

- 每个平台一个子目录。
- 封面图放在该目录的 `boxart/` 子文件夹下。
- 图片按游戏文件名（不含扩展名、忽略大小写）匹配，优先使用 `.png` > `.jpg` > `.jpeg`。
- `FBNEO`、`MAME` 等街机目录会自动跳过 Gamelist 生成。

---

## 注意事项

- 安装前会提示目标磁盘剩余空间，请确认足够后再继续。
- 安装过程会直接写入目标磁盘，建议先备份重要数据。
- 目标盘中已存在的同名文件会被覆盖。
- 生成 Gamelist 会直接覆盖目录下的 `gamelist.xml`。

---

## 构建

```bash
go build -o retro-tool.exe .
```
